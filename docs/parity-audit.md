# Parity audit: is it a gnuton feature?


Generated by `tools/parity-audit.py` by comparing an extracted stock
ASUSWRT rootfs with an extracted gnuton rootfs. Re-run it after downloading
new firmware to keep the feature kinds honest.

Method: a file that exists **only in gnuton** proves gnuton adds something;
a file in **both** proves the feature is stock ASUSWRT that gnuton merely
inherits. That is how each plan's `Kind` was chosen.

Directories compared: `www/`, `usr/sbin/`, `sbin/`, `usr/bin/`, `bin/`.

Totals: gnuton 1678 files, stock 1590 files, gnuton-only 119, stock-only 31.
