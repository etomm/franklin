# DHCP static leases / custom config

**Category:** DNS  
**Modes:** Router (DHCP server)  
**Status:** `stock`  
**Kind:** stock  
**Required:** no  
**Upstream:** stock ASUS

## Dependencies

- [dnsmasq-custom](dnsmasq-custom.md)

## Build / install (separable)

Nothing to build: stock firmware provides it. Franklin only must not break it.

## What it does

Pin IP addresses to MACs and add custom DHCP options for the LAN.

## How gnuton implements it

`dnsmasq` `dhcp-host` entries generated by `rc` from nvram; custom `dnsmasq.conf.add` on Merlin.

## Requirements

`dnsmasq` (stock), DHCP server enabled, writable `/jffs` for extra fragments.

## Franklin approach

Stock DHCP + static leases work; extra options go through dnsmasq-custom.

## Tested / verified

`Advanced_DHCP_Content.asp` present on stock and gnuton (both contain the static-lease fields).

## Risks / notes

AP mode has no local DHCP server — depends on the main router.

## Why this kind (evidence)

stock: `Advanced_DHCP_Content.asp` and `Main_DHCPStatus_Content.asp` exist with the same static-lease support in BOTH rootfs.
